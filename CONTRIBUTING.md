# Como contribuir com o FluentIA

Obrigado por ajudar um projeto gratuito de ensino de inglês.

## Antes de enviar alteração

1. preserve a gratuidade das funções educacionais essenciais;
2. não copie conteúdo, marca, imagens ou materiais protegidos de outros cursos;
3. não introduza promessas falsas de fluência;
4. não reduza os critérios das provas finais para facilitar aprovação;
5. não adicione rastreamento invasivo ou coleta desnecessária;
6. execute `npm run verify`.

## Pull requests

Explique:
- o problema;
- a mudança;
- como testar;
- impacto pedagógico;
- impacto em privacidade/acessibilidade, se existir.

## Conteúdo pedagógico

Novas aulas devem ter:
- objetivo claro;
- explicação curta;
- exemplos naturais;
- exercício de recuperação;
- aplicação prática;
- revisão posterior;
- nível compatível com a trilha.

## Bugs

Inclua navegador, dispositivo, versão, passos para reproduzir e resultado esperado.

## Certificação

Não altere textos para sugerir que o certificado interno do FluentIA é equivalente a certificações oficiais.
